Note: a plain anchor download never opens a Save dialog — the browser downloads straight to its download folder. This uses the File System Access API (showSaveFilePicker), which opens a real Save dialog in Chromium/Helium.

Completing a save in yazi: TUI managers cannot type a new filename. The portal pre-creates the suggested file, so hover test.txt and press Enter to confirm (overwrites it with the real content). Quitting with q writes nothing and reports (cancelled) — picking a directory is not enough in save mode, the file itself must be confirmed. To save under a different name: navigate to the target directory, create an empty file with that name (yazi a), hover it and press Enter.
